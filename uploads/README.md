# Upload these two files

- **BeyondTouch-Liverpool-50fps.mp4** — Guided review, 1920×1080, H.264, 50 fps.
- **BeyondTouch-Liverpool.png** — matching 1920×1080 project picture.

These feature Liverpool v Everton, 4 December 2019, with Sadio Mané as the movement
focus and Divock Origi as the goal-context scorer. Paths and arrows identify the
runner, defender-response candidate, covering candidate and scorer. The story
explicitly identifies the unconfirmed link to the finish.

The video interpolates the real educational **20 Hz** source positions before
rendering. It pauses at decision points, shows one possible space at a time, then reveals the
observed continuation. Opening and closing holds are included. **50 fps is presentation cadence, not 50 Hz captured tracking.**
All movement metrics are calculated on the original native samples. The source
has partial coverage and unverified nominal pitch scaling. See
Liverpool-50fps-metadata.json for encoding, source and file provenance.

The older Di María pair is retained for history; use the Liverpool pair above for
the current submission.
